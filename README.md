# (Mu)PDF engine replacement for Obsidian

i want to read bunch of pdfs right in an obsidian tab. obsidian uses PDF.js as
the pdf rendering engine. its slow as hell. my laptop was fast for 2017, but is
slow now. laptop is the same. pdfs are the same. the 2026th year of our lord
is slow.

this plugin replaces PDF.js with MuPDF for rendering pdfs. it's fast. it's simple.
it works with the outliner.

i might add more features and break things.

also, this is highly experimental AI slop, so it might break under your feet.
when it does, please leave a GitHub Issue.
